# Founder Journal — Engineering Identifier Reference

**Date:** 30 July 2026  
**Stage:** Engineering Governance

## Topics Discussed

- Creating the authoritative identifier-prefix registry.
- Preserving established IDs and compatibility exceptions.
- Defining reserved prefixes, token conventions, lifecycle, and registration.
- Selecting terminology as the next reference.

## Founder Input

The founder selected `REF-IDENTIFIERS` as the first authoritative governance reference.

## Key Insights

- A reference records the catalogue; standards define mandatory behaviour.
- The repository already uses discipline-specific principle prefixes, so a universal `PR` prefix would create conflict.
- Established IDs should not be renamed merely for cosmetic consistency.
- Reserved prefixes should be activated only when their artefact types have real governance.

## Decisions

- Published `REF-IDENTIFIERS` v1.0.0 as Draft.
- Preserved `EP`, `AP`, `AR`, `CP`, `TP`, `SP`, `OP`, and `PP` principle families.
- Preserved `DOC-STYLE`, `TERM-STANDARD`, and `PB-AUTHORING` as compatibility identifiers.
- Selected `REF-TERMINOLOGY` as the next reference.

# Engineering Prompt Patterns Reference

## Purpose

Provide reusable, tool-neutral task and prompt patterns for common engineering activities without replacing the governed workflow, safe-context rules, verification, or human approval required by `PB-AI-ENGINEERING`.

## Planned Contents

- Task-definition pattern.
- Context and constraint pattern.
- Requirements, architecture, and technical-design patterns.
- Coding, refactoring, review, and testing patterns.
- Debugging, incident, documentation, SQL, and infrastructure patterns.
- Output, evidence, uncertainty, and prohibited-action clauses.
- Pattern selection, adaptation, validation, and retirement guidance.

## Status

🔴 Planned

Patterns are not approved shortcuts. Every use remains subject to task-specific context, security, verification, and engineering judgement.

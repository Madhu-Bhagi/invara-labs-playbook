# Engineering

## Purpose

This section defines how engineering is practiced at Invara Labs.

It contains the principles, standards, processes, and playbooks that guide how software is designed, built, tested, deployed, and maintained.

The goal is not only to build software, but to build software that is reliable, maintainable, scalable, and trusted.

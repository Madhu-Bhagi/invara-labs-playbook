Defines why Invara Labs exists.

Primary document:

- Founder Vision

### 2. Direction

Defines what Invara Labs does and what it aims to become.

Primary documents:

- Mission Statement
- Vision Statement

### 3. Behaviour

Defines how the company makes decisions and behaves.

Primary documents:

- Core Values
- Founder Principles
- Company Manifesto

### 4. Engineering

- Engineering Philosophy
